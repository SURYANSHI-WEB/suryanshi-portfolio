# Suryanshi's Portfolio

Hi! I'm Suryanshi
This is my personal portfolio website built from scratch using HTML, CSS, and JavaScript.

It reflects who I am as a Full Stack Developer in progress. Someone who enjoys building complete applications, refining UI details, and continuously improving technical depth.

---

## About The Project

This portfolio showcases:

- The projects I've built
- My interests beyond just writing code
- A functional contact form with EmailJS integration
- Interactive JavaScript features added in Week 2

The goal was to build something clean, responsive, and structured without relying on templates or frameworks.

---

## Tech Stack

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES5)
- EmailJS (for contact form)
- Responsive Design
- Git & GitHub

Built fully from scratch.

---

## Features

- Responsive layout (mobile & desktop friendly)
- Structured semantic HTML with ARIA accessibility labels
- Clean, maintainable CSS architecture
- Interactive hobby benefits list — add and delete items dynamically
- Contact form with EmailJS integration and alert confirmation
- Dynamic footer showing live date and time
- Smooth fade-in scroll animations
- Custom favicon and polished UI details

---

## What I Learned Building This

Building this portfolio helped me strengthen more than just my HTML and CSS skills. It taught me:

- How to structure a website using semantic HTML
- How to design clean and responsive layouts using Flexbox and Grid
- The importance of spacing, alignment, and visual consistency
- How to debug layout issues and refine UI details
- How to manipulate the DOM dynamically using JavaScript
- How to handle form submission events and integrate EmailJS
- How to use the Intersection Observer API for scroll animations
- How to write accessible markup using ARIA labels
- How to version control and deploy projects using Git & GitHub

Most importantly, it helped me understand that writing clean, organized code is just as important as making something look good.
